- `test_meta_cles_schema` : `META_KEYS.issubset` → **verrouille la non-suppression** des clés `meta` du schéma (laisse passer les ajouts). Bon invariant pour B3.

- `test_coherence_celsius_fahrenheit` : `|F − (C*9/5+32)| ≤ 3` → **détecte une °C ou °F altérée** (non tautologique : croise deux champs indépendants), tolérance large justifiée par les arrondis → non fragile.
- `test_minimums_positifs_plausibles` : bornes 50–100 °C / 120–215 °F → attrape un minimum aberrant.
- `test_repos_mentionne_quand_present` : ≥1 ligne `restMinutes>0` → sanity du repos pièces entières.

**Pas de fragilité sur le wording** des notes (conforme à la consigne de la story). Non bloquant (decisions #4 reste l'autorité ; valeurs actuellement exactes).

2. **[Observation — dismiss] Redondance note poisson/œufs entre `standards[].note` et `meta.verification.lines[].note`.** Léger doublon documentaire ; sans impact (additif, B3 ne lit pas `meta.verification`). **Dismiss** : cohérence intentionnelle (journal de vérification).
